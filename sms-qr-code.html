How to use an SMS QR code

Place an SMS QR code on flyers, signs, event materials, menus, or product packaging. After scanning, supported phones can open the messaging app with the recipient and message prefilled.

SMS QR code tips

  • Include the country code when sharing a number internationally.
  • Keep the prefilled message short and clear.
  • Test the QR code on both iPhone and Android before printing.

How a PDF QR code works

A QR code normally contains a URL, not the PDF file itself. When someone scans it, their device opens the PDF link in a browser or compatible app.

Before printing

  • Make sure the PDF URL is public and uses HTTPS.
  • Test the link on a phone outside your own account.
  • Keep the destination URL stable after printing.
